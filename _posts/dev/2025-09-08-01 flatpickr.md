flatpickr 공식 플러그인에는 monthSelector 만 존재
yearSelector 기능이 필요해flatpickr v4.6.13 기준으로 개발

매개변수

dateFormat - 실제 값
altFormat - 표시되는 값
theme - 'light', 'dark' (css)
minDate - selector 에 표시되는 최소 년도
maxDate - selector 에 표시되는 최대 년도
maxRangeLength - mode range 시 선택 가능한 기간 범위 (종료일 - 시작일, 3 인 경우 예를 들어 2022 ~ 2025 가 최대 범위)

```js
new flatpickr(input, {
  plugins: [
    yearSelectPlugin({
      minDate: "2017-01-01",
      maxDate: moment(),
      showRangeError: false,
      maxRangeLength: 4,
    }),
  ],
});
```

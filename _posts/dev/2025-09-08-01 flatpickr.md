flatpickr 공식 플러그인에는 monthSelector 만 존재  
yearSelector 기능이 필요해 flatpickr v4.6.13 기준으로 개발

매개변수

dateFormat - 실제 값  
altFormat - 표시되는 값  
theme - 'light', 'dark' (css)  
minDate - selector 에 표시되는 최소 년도 (new Data(value) 로 검증하기 때문에 'YYYY-MM-DD' 형식으로 넣어야함)  
maxDate - selector 에 표시되는 최대 년도 (new Data(value) 로 검증하기 때문에 'YYYY-MM-DD' 형식으로 넣어야함)  
maxRangeLength - mode range 시 선택 가능한 기간 범위 (종료일 - 시작일, 예를 들어 3 인 경우 2022 ~ 2025 가 최대 범위)

```js
new flatpickr(input, {
  plugins: [
    yearSelectPlugin({
      minDate: "2017-01-01",
      maxDate: "2025-01-01",
      showRangeError: false,
      maxRangeLength: 4,
    }),
  ],
});
```

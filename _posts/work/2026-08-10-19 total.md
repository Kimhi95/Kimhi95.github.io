급수

주요 업무는 다음처럼 정리할 수 있습니다.
급수공사 공사업체 관리: 목록·등록·상세·수정·삭제, 주소 검색 및 유효성 검사
단가 관리: 단가항목 CRUD, 구성일위대가, 사용자 지정 항목, 기준연도 관리
엑셀 기능: 단가 일괄 업로드, 양식 다운로드, 통계·설계서·현장조사서 출력
단가 변동 내역: 목록·상세 조회, 검색 초기화, 데이터 및 표시 오류 개선
통계 현황: 급수민원·준공·급수공사 현황, 차트 및 엑셀 다운로드
문서 출력: 공사신청서 PDF, 공사설계서·준공대장 Excel, ZIP 일괄 다운로드
전자결재 연계: 설계서 저장 및 저장 폴더 생성
공통 UI/안정화: 모달, 페이지 전환 효과, 이벤트 정리, 입력값 인코딩, CSS 개선
보안: 취약점 점검 결과 반영
경력기술서 형태로 표현하면:
JDK 8 및 레거시 Spring 기반 급수공사관리 시스템에서 공사업체·단가·통계·문서출력 기능을 개발했습니다. Vanilla JavaScript 기반 화면과 Excel/PDF 출력, 일괄 업로드, 전자결재 연계 기능을 구현했으며, 운영 과정에서 발생한 데이터 검증·UI·보안 문제를 지속적으로 개선했습니다.

Apache HTTP Server 및 URL 접속 환경

- 개발 서버와 운영 서버에 Apache HTTP Server 구성
- IP 주소와 포트를 직접 입력하던 접속 방식을 실제 서비스 URL 기반으로 전환
- 개발·운영 환경별 URL 및 VirtualHost 구성
- Apache Reverse Proxy를 통해 외부 URL과 Spring Boot 애플리케이션 연동
- 서비스별 URL과 내부 애플리케이션 포트 매핑
- 사용자에게 내부 서버 IP와 애플리케이션 포트가 노출되지 않도록 구성
- Apache를 애플리케이션의 외부 진입 지점으로 구성
- 개발·운영 환경의 접속 주소를 분리하여 배포 및 접근 편의성 개선

보고서용 최종 요약은 다음과 같이 수정할 수 있습니다.
2025년 10월부터 O2SYSTEM 통합시스템 개발에 참여하여 현재까지 총 592건의 SVN 커밋을 수행하였다. 프로젝트 초기 소스 통합과 공통 구조 정비를 시작으로 착수, 착수 변경, 완료, 계약, 매출, 사업비, 수행계획, 인건비 및 통계 기능을 개발하였다. 프로젝트 상태와 사용자 권한에 따른 검증 로직을 구축하고 조직·자원관리, JWT 인증, Profile 조회 구조, PDF·Excel 출력 및 Vanilla JS 기반 화면의 사용성과 안정성을 개선하였다. 또한 Linux 기반 개발 서버와 운영 서버를 직접 구축하고 PostgreSQL, Redis Cluster, RedisInsight 및 Jenkins를 설치·구성하여 데이터베이스, 캐시, 모니터링, 빌드 및 배포 환경을 마련하였다. Apache HTTP Server의 VirtualHost와 Reverse Proxy를 구성하여 IP 주소와 포트를 직접 입력하지 않고 실제 서비스 URL을 통해 개발 및 운영 시스템에 접속할 수 있는 환경을 구축하였다. 현재는 Redis Standalone 구조를 Cluster 방식으로 전환하고 Lettuce 토폴로지 갱신, 자동 재연결, JSON 캐시 직렬화 및 TTL 정책을 적용하는 작업을 진행하고 있다.

   해외 온라인 저작권 침해 대응 시스템의 통합관리 기능을 개발하였습니다. 수집·분석, ICOPW·ICOPT·ICOPG, 해외 유통 현황, 빅데이터 데이터를 통합 관리할 수 있도록 목록·상세·등록·수정·엑셀 처리 기능을 구현하였으며, Spring Legacy 기반 Controller/Service, SQL Mapper 및 Vanilla JS 화면까지 풀스택으로 담당했습니다. 또한 통합조회 데이터 갱신과 통계 생성 기능을 구축하고, 대응 실적·장르·언어·기관별 통계 및 외부 분석 리포트 연동 기능을 개발했습니다.
